# Four Conceptual Layouts

The in-app `#/concepts` route renders all four as labeled low-fidelity diagrams. The rest of the app supplies connected high-fidelity screens.

1. **Discovery first (selected Home):** header → focused search/location → compact categories → recent product grid. Appropriate for exploratory visitors; avoids showing advanced price controls before intent is established.
2. **Search workspace (Browse):** header → search → active filter chips → sidebar filters + result grid and sorting. Appropriate for visitors with a specific item, budget and city.
3. **Trust and context (Details):** header/back → large gallery + purchase facts/seller/contact → description/specifications. Keeps the primary communication action adjacent to its product context without claiming real seller verification.
4. **Guided task (Add):** header → three-step progress → grouped form/image preview → review/edit → success. Prevents accidental publication and makes task completion explicit.

These alternatives are conceptual proposals, not four experimentally compared designs. Their complementary ideas were applied to the corresponding final screens. No A/B testing or participant preference is claimed.
